# 菜单、音频与完整游戏循环设计

## 目标

让程序从标题菜单开始，并形成可重复游玩的闭环：标题菜单进入关卡，关卡可以暂停，
最后一命死亡进入 Game Over，完成关卡进入 Stage Clear，之后可以重新开始、返回标题
或退出。BGM 与音效实际播放，音量和显示模式可在设置中修改并持久保存。

## 设计原则

- 视觉和交互参考《东方红魔乡》：标题背景、右侧纵向菜单、红白选中状态、方向键移动、
  Z 确认、X 或 Esc 返回。
- 只展示当前真正可用的入口。没有 Extra、Replay、Music Room 时不放无效菜单项。
- 游戏逻辑仍由现有 `Game` 和实体层负责；场景控制、菜单绘制和音频不进入实体类。
- 固定步长只推进正在游玩的关卡。菜单、暂停和结果页不会让敌人或弹幕继续运行。

## 场景与转换

应用层持有以下状态：

- `TITLE`：开始游戏、设置、退出。
- `OPTIONS`：BGM 音量、音效音量、窗口模式、返回。
- `PLAYING`：现有关卡逻辑。
- `PAUSED`：继续、重新开始、返回标题、退出。
- `GAME_OVER`：重新开始、返回标题、退出。
- `STAGE_CLEAR`：重新开始、返回标题、退出。

转换规则：

1. 启动总是进入 `TITLE`。
2. `TITLE -> PLAYING` 时创建全新的关卡会话。
3. `PLAYING` 中按 Esc 进入 `PAUSED`，不直接退出程序。
4. `PAUSED -> PLAYING` 继续使用原会话；“重新开始”创建新会话。
5. 玩家进入 `State.DEAD` 后，待死亡冲击波开始显示即进入 `GAME_OVER`。
6. 关卡的所有出生计划均完成、场上无敌人且 BOSS 脚本完成后进入 `STAGE_CLEAR`。
7. 返回标题或重新开始时，清空按键闩锁和固定步长积压，避免旧输入穿透到新场景。
8. `pygame.QUIT` 在任何场景都退出；标题和结果页选择“退出”也退出。

## 输入

菜单输入使用按键按下事件，不使用键盘轮询：

- 上/下：移动光标。
- 左/右：调整设置值。
- Z 或 Enter：确认。
- X 或 Esc：返回；游戏中 Esc 为暂停。

菜单忽略按键自动重复造成的同帧多次切换。切换场景时清空当前事件消费状态。

## 界面

标题页使用 `assets/sprites/backgrounds/title_screen_wallpaper.jpg`，按逻辑分辨率裁切或
缩放。标题与菜单使用现有字体 `DFPPOPCorn-W12.ttf`。菜单文本靠右纵向排列，未选中
项为暖白，选中项为红色并带轻微水平偏移。

暂停与结果页覆盖在最后一帧游戏画面上，增加半透明暗层，中央显示状态标题和菜单。
Game Over 明确提示本轮结束；Stage Clear 明确提示关卡完成。

## 设置持久化

设置对象包含：

- `bgmVolume`：0 到 10，默认 7。
- `soundVolume`：0 到 10，默认 8。
- `fullscreen`：布尔值，默认关闭。

配置保存为 JSON。Windows 使用 `%APPDATA%/TouhouProject/settings.json`；环境变量不可用
时回退到用户目录下的 `.touhou-project/settings.json`。代码不写死任何机器路径。

文件缺失、JSON 损坏、字段缺失或值越界时使用默认值或钳制后的值，游戏仍可启动。
每次修改设置立即应用并保存。全屏切换重建窗口，但保留当前场景。

## 音频

新增一个集中式音频管理器，独占 `pygame.mixer.music` 和 `pygame.mixer.Sound`：

- 标题与设置页播放标题曲 `01.-A-Dream-that-is-more-Scarlet-than-Red_1.wav`。
- 普通关卡播放现有 `08.-Voile_-the-Magic-Library_1.wav`。
- BOSS 出场后切换为 `09.-Locked-Girl-_-The-Girl_s-Secret-Room.wav`。
- 菜单移动、确认、取消，自机射击、炸弹、受击和死亡使用现有 `assets/music/sounds/`
  中对应音效。

BGM 和音效音量独立应用。音量为 0 时保持播放状态但静音，恢复音量时无需从头加载。
音频设备初始化失败时退化为静音模式，界面和游戏仍可运行。

为避免每帧重复播放，自机连射音效服从射击冷却；状态音效只在状态边沿触发。

## 代码边界

- `core/settings.py`：设置数据、校验、加载与保存，不依赖 pygame。
- `core/audio.py`：音乐和音效加载、切换与音量控制。
- `ui/menu.py`：菜单模型、事件处理和绘制。
- `main.py`：应用场景控制、关卡会话创建和现有游戏接线。
- `constants.py`：菜单颜色、默认音量等固定值仅在确有跨模块需要时加入。

`Player`、`Enemy`、`Bullet` 不直接播放声音，也不导入 UI。应用层通过状态变化和现有
场对象观察事件，调用音频管理器。

## 测试与验收

- 设置：默认值、损坏文件、越界钳制、保存后重载。
- 菜单：循环导航、确认、返回、左右调整、禁用同帧重复动作。
- 场景：启动标题、开始新局、暂停/继续、最后死亡进入 Game Over、重开与返回标题、
  关卡完成进入 Stage Clear。
- 音频：BGM/SE 音量独立、曲目不重复重载、初始化失败静音退化。
- 集成：无头运行菜单到游戏再到 Game Over 的转换。
- 打包：PyInstaller 收集新模块和所有音频资源；从项目目录之外启动 exe，确认不会崩溃。

人工验收包括菜单视觉、按键手感、暂停冻结、音量实际变化、全屏切换、死亡与通关闭环。

## 非目标

本轮不增加角色选择、难度选择、Replay、Extra、Music Room、排行榜或新的关卡内容。
这些入口在功能真实存在之前不显示。
